# Flappy Bird

This Flappy Bird game was generated by GitHub Copilot. It is a clone of the popular mobile game where players control a bird, navigating it through a series of pipes without hitting them.

## Features
- Simple and intuitive controls
- Increasing difficulty level
- High score tracking

## How to Play
- Press the spacebar to make the bird jump.
- Avoid hitting the pipes!
